# 0.1.7a — Wagon loop timetables

## Cel
Wagon receives a permanent repeating service pattern. The dispatcher defines the complete timetable while locomotives remain operational movement units controlled by signals and manual dispatching.

## Route definition

The user defines only the base station sequence:

`A-B-C-D`

The runtime expands it deterministically to:

`A-B-C-D-C-B-A`

Return-direction control points are therefore explicit rather than generated from outbound travel times.

## Timetable points

Every expanded point has two independent control times:

- arrival;
- departure.

The difference between arrival and departure is the planned dwell. Terminal manoeuvre time is represented by a longer terminal dwell instead of a separate coupling/decoupling schedule operation.

## Repetition

The same full-loop timetable repeats automatically during the game day. The timetable does not command a train to move; it records expected control points and measures actual arrival against them.

## Runtime state

Each wagon stores:

- schedule identity;
- current cycle;
- current timetable point;
- schedule state;
- calculated delay;
- last observed arrival;
- day of the last observation;
- planned dwell release time.

Because this state belongs to the wagon, coupling and decoupling do not transfer or recreate the timetable.

## Save

Runtime save schema is `2`. Schedule definition and runtime state are embedded in each wagon entry in `trains.json`, together with the existing vehicle technical data and passengers. Schema `1` files remain readable; vehicles from old saves have no timetable until configured by the player.

## UI

The existing `S` wagon menu remains the entry point. It now acts as the timetable editor rather than introducing a separate workflow. The player can build the base route, inspect the expanded loop and enter arrival/departure times for every control point.

## Scope

Automatic route selection, autonomous timetable driving, path finding, timetable conflict resolution, passenger transfer planning and economics remain outside 0.1.7a.
