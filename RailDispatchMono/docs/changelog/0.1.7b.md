# 0.1.7b — Timetable editor UI

**Data:** 2026-09-04

## Cel

Poprawa ergonomii istniejącego edytora rozkładu otwieranego pod `S`. Model rozkładu z `0.1.7a` pozostaje bez zmian.

## UI

- Edytor pozostaje w istniejącym workflow `S`.
- Trasa bazowa i tabela rozkładu są rozdzielone na czytelne sekcje.
- Dodane są jawne przyciski operacyjne zamiast polegania na klikaniu tekstu.
- Użytkownik może dodawać i usuwać stacje.
- Użytkownik może zmieniać kolejność stacji przyciskami `GÓRA` / `DÓŁ`.
- Tabela rozkładu ma osobne kolumny `STACJA`, `PRZYJAZD`, `ODJAZD`.
- Edycja czasów pozostaje bezpośrednia, ale aktywne pole jest jednoznacznie oznaczone.
- Długie nazwy stacji i komunikaty nie mogą nachodzić na sąsiednie kontrolki.
- Przyciski `ZAPISZ`, `USUŃ ROZKŁAD` i `ANULUJ` są wyraźnie oddzielone od zawartości tabeli.
- Dla dłuższych tras przewidziane jest przewijanie zawartości zamiast zwiększania panelu poza ekran.

## Zakres funkcjonalny

Nie zmieniamy zasad rozkładu: wagon nadal posiada rozkład, trasa `A-B-C-D` jest rozwijana do `A-B-C-D-C-B-A`, a każdy punkt posiada niezależny przyjazd i odjazd.

## Weryfikacja

Po implementacji wymagane jest sprawdzenie wizualne menu `S` oraz zwykły build rozwiązania. Brak automatycznego CI w repozytorium.
