# [0.0.12a] — Depot buildings, UI/layout and desktop window improvements

Data: 2026-08-31

## Depot

- Depot is now a real world building rather than only a UI spawn button.
- Added `DepotController` for player-built depot instances.
- Added programmatic `DepotRenderer`; no external graphics assets are required.
- Added `TrackBuildMode.Depot`.
- `9` / NumPad `9` activates depot construction mode.
- Left click places a depot building.
- Right click on a depot removes it; Shift + right click is also supported.
- Existing depot model remains suitable as a future route origin for `0.0.13`.

## Passenger floating text

- Passenger exchange is represented independently per wagon.
- Boarding is displayed as `+X` and alighting as `-X`.
- A zero/net-change value must not replace separate boarding/alighting events.
- Floating text uses programmatically rendered `SpriteFont` text with upward movement and fade-out.

## UI / Window

- Default desktop window increased from `1280x720` to `1600x900`.
- Desktop window is user-resizable.
- Settings expose window-size presets: `1280x720`, `1600x900`, `1920x1080`.
- Window size is persisted with the existing settings system.
- HUD work is based on the current viewport rather than assuming the old 1280x720 size.

## Documentation

- Added an authoritative current-state document for `0.0.12` and `0.0.12a`.
- Obsolete feature descriptions are being replaced by current implementation status.

## Known limitations

- Route planning is not implemented yet; this remains the main target of `0.0.13`.
- Coupling/decoupling is not implemented yet.
- Passenger demand is still generated by the random provider; city-based demand is reserved for the future city system.
- The current UI still uses programmatic rectangles/text rather than external UI art assets.
