# 0.1.3e — Myra HUD consolidation and navigation

## Gameplay HUD

- Fixed `x1`, `x2`, `x5` so all three controls use equal fixed-width columns.
- Kept the controls directly below the simulation clock.
- Train and station lists remain exclusively Myra-owned; the legacy SpriteBatch object list is no longer used.
- Clicking a train now centers the camera on the train instead of placing it at the viewport corner.
- Clicking a station now centers the camera on the station's actual center.

## Migration status

The gameplay HUD is now Myra-only for clock/day, speed controls, build tools, trains and stations. Legacy world-rendered UI is intentionally limited to world-specific interaction surfaces that have not yet been migrated.

The remaining planned UI migrations are tracked as future `0.1.3x` work rather than duplicated alongside Myra.
