# 0.1.4d — RadioStop: wcześniejsze hamowanie przed kolizją

## Zmiany

- Zwiększono dystans bezpieczeństwa mechanizmu `RadioStop` z **2 do 3 kratek**.
- Pociąg wykrywa inny pociąg na swojej aktualnej trasie wcześniej i zatrzymuje się **3 kratki przed zajętą pozycją**, o ile nie ma wcześniej chroniącego go semafora.
- Zachowano istniejącą ochronę przed kolizją oraz logowanie zdarzenia `RadioStop`.
- Logika sygnalizacji pozostaje nadrzędna: wykryty sygnał ochronny nadal może zwolnić działanie `RadioStop` dla danego odcinka.

## Technicznie

- `TrainCollisionController.SafetyDistanceCells`: `2f` → `3f`.
- Zakres skanowania trasy pozostaje ograniczony do lokalnej detekcji kolizji.
