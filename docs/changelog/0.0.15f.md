# [0.0.15f] — Stabilizacja systemu pauzy i zarządzania ekranami

**Data:** 2026-08-31

## Pause system

- Naprawiono logikę pauzy w `GameplayScreen`.
- Dodano poprawne zarządzanie stanem przez `TogglePause()`.
- `ESC` poprawnie rozpoczyna i kończy pauzę.
- Zapobiegnięto tworzeniu zduplikowanych ekranów pauzy.

## PauseScreen

- Naprawiono wyjątki `NullReferenceException` podczas rysowania menu pauzy.
- Poprawiono obsługę `IsPopup`.
- Uporządkowano ładowanie zasobów wymaganych przez ekran pauzy.
- Menu pauzy jest wyświetlane jako overlay nad aktywną rozgrywką.

## ScreenManager

- Poprawiono indeksowanie ekranów i zabezpieczenia operacji na kolekcji ekranów.
- Dodano bezpieczniejszą obsługę aktywnego `ScreenManager` w cyklu życia gry.
- `ScreenManager` jest poprawnie dodawany do komponentów gry.

## Content / Fonts

- Poprawiono ładowanie czcionki używanej przez system ekranów.
- Uporządkowano zakres glifów `Hud.spritefont`, w tym polskie znaki.

## Diagnostics

- Dodano diagnostyczne logowanie zmian stanu pauzy i zarządzania ekranami.
- Logi mają ułatwiać wykrywanie problemów z kolejnością aktualizacji i renderowania ekranów.

## Result

`0.0.15f` jest bieżącym stabilizacyjnym stanem linii `0.0.15`. Save/Load mapy pozostaje dostępne z menu pauzy, a pełna persistence pociągów, wagonów, rozkładów, pozostałego stanu świata i ekonomii pozostaje poza obecnym zakresem.

## Known limitations

- System save nie zapisuje jeszcze całego stanu symulacji jako jednego kompletnego pliku.
- Persistence pociągów i wagonów pozostaje do implementacji.
- Pełne ładowanie rozkładów do aktywnej symulacji pozostaje do implementacji.
- Ekonomia pozostaje niezaimplementowana.
- Drobne problemy UX i techniczne pozostają znane i będą usuwane w kolejnych poprawkach.
