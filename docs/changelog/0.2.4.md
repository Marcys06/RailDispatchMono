# 0.2.4 — Rodzaje torów i trakcji

**Data:** 2026-09-06

## Infrastruktura

- Rozdzielono geometrię toru od jego roli eksploatacyjnej.
- Dodano `TrackType`: `Mainline`, `Secondary`, `Siding`, `Platform`.
- Dodano `LineClass`: `Local`, `Regional`, `Mainline`, `Magistral`.
- Dodano `TractionSystem`: `None`, `DC`, `AC`.
- `TrackCell` przechowuje typ, klasę linii, trakcję i model zużycia.
- Przygotowano limity infrastrukturalne klasy linii: Vmax i nacisk osi.

## Tabor

- Zachowano istniejący `TractionType` jako napęd `Electric` / `Diesel`.
- Dodano wielosystemową zdolność lokomotywy przez zbiór obsługiwanych systemów elektrycznych.
- EP07 przypisano do DC, EU200 do AC.
- Lokomotywy dieslowskie pozostają niezależne od elektryfikacji.

## Edycja

- Dodano F8 jako edytor infrastruktury toru pod kursorem.
- Istniejący tor można zmienić pod względem typu, klasy linii i trakcji bez zmiany geometrii.
- `TrackBuilder` przenosi wybrane parametry infrastruktury na nowo budowane segmenty.

## Zapisy

- `map.json` przechodzi na schemat `2`.
- Zapisywane są typ toru, klasa linii, trakcja i zużycie.
- Stare zapisy nie są wymagane do zachowania kompatybilności.

## Zakres świadomie odłożony

- brak ekonomii;
- brak kosztów budowy/utrzymania;
- brak aktywnego zużywania infrastruktury;
- brak automatycznego planowania trasy pod trakcję;
- brak automatycznego rozwiązywania konfliktów infrastrukturalnych;
- brak przebudowy fizyki ruchu.

## Roadmapa

0.3.0 infrastruktura → 0.4.0 ekonomia → 0.5.0 publiczny rozkład → 0.6.0 pasażerowie → 0.7.0 fizyka → 0.8.0 kryzysy → 0.9.0 sieć → 1.0.0 full release.
