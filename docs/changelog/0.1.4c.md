# 0.1.4c — Train speed display and signal stop distance

## Scope

`0.1.4c` continues the train-mechanics work from `0.1.4b`.

## Changes

- Train speed shown to the player is always presented in **km/h**.
- Internal train speed remains in physical `m/s`; this change affects only the user-facing representation.
- When braking to a `Stop` signal, the target stopping position is **0.3 map cells before the signal**.
- The existing Stop/BlockController braking system remains authoritative; the 0.3-cell offset changes the stopping target rather than introducing a second Stop controller.
- The existing simulation spatial scale from `0.1.4b` remains authoritative (`1 map cell = 10 metres`), so the Stop target offset corresponds to 3 metres.

## Preserved behavior

- Signal speed restrictions from `0.1.4a` remain unchanged.
- `Clear` handling and return to Vmax remain unchanged.
- StationController remains authoritative for station stops.
- Internal physical speed calculations remain in metres per second.

## Documentation policy

This is a lettered development stage. No `current-state-0.1.4c.md` is created. The next authoritative current-state snapshot will be `0.1.4pre`.
