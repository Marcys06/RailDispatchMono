# 0.1.2c — Myra main menu migration

**Date:** 2026-09-01

## Scope

Accelerated the planned Myra migration by completing the shared desktop plumbing and migrating the Main Menu surface in the same stage.

## Changes

- Expanded `MyraUIManager` with:
  - viewport-based `BoundsFetcher`;
  - shared root widget ownership;
  - root clearing when ownership ends;
  - safe rendering when no root is active.
- Added `MyraMainMenuView` using standard Myra widgets.
- Migrated Main Menu visual presentation to Myra.
- Migrated Main Menu mouse/keyboard interaction to Myra Desktop.
- Preserved `MainMenuScreen`, `MenuScreen` and `MenuEntry` types and their existing lifecycle contract.
- Rendered the shared Myra desktop once after the ScreenManager screen stack.
- Kept Load Game, Settings, About, Pause and gameplay UI on the existing implementation for later stages.

## Architecture

`ScreenManager` remains responsible for screen lifecycle, transitions and screen ownership. Myra owns the widget surface only for screens that explicitly install a root into the shared `MyraUIManager`.

The Main Menu clears the shared desktop in `UnloadContent`, preventing its widgets from leaking into subsequent screens.

## Stage discipline

`0.1.2a` and `0.1.2b` remain immutable. Future defects are corrected in the next lettered stage rather than amending this stage.
