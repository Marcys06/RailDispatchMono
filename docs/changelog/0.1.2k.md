# 0.1.2k — Przebudowa systemu pauzy

## Pauza

System pauzy został przebudowany od podstaw bez zmiany widoku `MyraPauseView`.

### Nowa architektura

- `GameplayScreen` jest jedynym właścicielem stanu `_isPaused`.
- Pauza nie jest już osobnym `GameScreen` i nie jest dodawana do `ScreenManager` jako popup.
- `MyraPauseView` pozostaje wyłącznie warstwą UI i dostarcza callbacki dla czterech akcji.
- Akcje z Myra są przekazywane przez `MyraUIManager.QueueAction()` i wykonywane na początku następnej klatki `Update`, poza `Desktop.Render()`.
- `ESC` oraz przycisk `WZNÓW GRĘ` kończą pauzę przez ten sam `ResumeGame()`.
- `ZAPISZ GRĘ` i `WCZYTAJ GRĘ` są wykonywane przez `GameplayScreen`, bez pośredniego ekranu pauzy.
- Podczas pauzy `GameplayScreen` zatrzymuje symulację oraz wejście gameplayowe, ale nie dodaje popupu do `ScreenManager`.
- Dzięki temu popup pauzy nie może przejąć kolejności aktualizacji ani zablokować obsługi UI Myra.

### Usunięto

- `PauseScreen.cs` — poprzedni system oparty o osobny `GameScreen`, eventy i popup został usunięty.

### Kolejność akcji

```text
Myra Button.Click
    -> MyraUIManager.QueueAction(...)
    -> następny Game.Update()
    -> GameplayScreen.ResumeGame / SaveMap / LoadMap
```

`MyraPauseView.cs` nie zawiera logiki stanu gry i pozostaje nietknięty jako warstwa prezentacji.
