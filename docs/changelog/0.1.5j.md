# 0.1.5j — Consolidated coupling and shunting documentation

**Data:** 2026-09-03

This document consolidates the former `0.1.5e` command-layer notes into the final 0.1.5 development documentation. The final release state is `0.1.5pre`; `j` is retained only as the consolidated historical sub-milestone identifier.

## Controls

- `C` — coupling against the nearest valid outer-boundary candidate.
- `X` — decoupling of the wagon under the cursor.
- `F6` — manual shunting toward `3 km/h` while held over a train.
- `F7` — train travel-direction reversal, accepted only at `0 km/h`.

The former configurable `F6/F7/F8` coupling-speed profiles are no longer part of the control scheme. Coupling uses a fixed `6 km/h` shunting limit.

## Coupling

`C` discovers valid candidates through `TrainManager.GetCouplingCandidates()` and delegates the authoritative physical operation to `CouplingService`.

Validation remains based on:

- outer vehicle boundaries;
- concrete `VehicleEnd` values;
- physical `CouplingSpecification` / `CouplerType` compatibility;
- endpoint distance and alignment;
- train speed limits.

Vehicle order is preserved when two trains are merged.

## Decoupling

`X` requires a wagon to be under the cursor. If both physical ends have runtime connections, the rear connection is preferred. The split is performed by `CouplingService.Decouple()`.

Decoupling is allowed only below `6 km/h`. The detached section becomes a separate stopped train while preserving its vehicle order, internal runtime couplings and physical positions.

## Manual shunting

`F6` is a direct manual-shunting control. While held over a train, it accelerates that train toward `3 km/h` and bypasses the automatic RadioStop/collision stop path for that targeted train. Other trains remain on the normal safety path.

## Final relationship with F7

F7 is no longer a coupling-speed command. It is exclusively the train travel-direction command described by the final `0.1.5pre` contract:

```text
[L][A][B][C]  ->

F7 at 0 km/h

[L][A][B][C]  <-
```

The composition order and physical positions do not change.

## Scope

This sub-milestone documents the command layer only. The final implemented state, including curve trajectory following and per-vehicle curve orientation, is documented in `docs/changelog/0.1.5pre.md`.
