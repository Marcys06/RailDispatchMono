# [0.0.14] — Podstawowy system kolizji

Data: 2026-08-31

## Collision Protection

- Dodano `TrainCollisionController` jako osobny komponent odpowiedzialny za pierwszą wersję ochrony przed kolizją.
- Pociąg wykrywa inne składy na rzeczywiście wybranej drodze torowej.
- Prosty odstęp bezpieczeństwa wynosi **2 komórki**.
- Jeżeli przed przeszkodą nie ma semafora, pociąg otrzymuje komendę `RadioStop` i zatrzymuje się.
- Jeżeli semafor znajduje się przed innym pociągiem, to semafor ma pierwszeństwo i system kolizji nie ingeruje w jazdę.
- Po zwolnieniu drogi `RadioStop` zostaje wyczyszczony i pociąg ponownie podlega normalnej logice semaforów.

## RadioStop

Dodano pierwszą wersję komendy:

`Train.RadioStop()`

Na tym etapie komenda jedynie ustawia prędkość pociągu na zero. Została wydzielona jako osobne API, aby w przyszłości mogła zostać zastąpiona systemem eventów/komend dyspozytorskich.

## Spawn Protection

- Dodano walidację podczas dodawania pociągu do `TrainManager`.
- Nowy skład nie zostanie dodany, jeżeli którykolwiek jego wagon lub lokomotywa zajmuje komórkę już zajętą przez inny skład.
- Walidacja obejmuje cały skład, nie tylko lokomotywę.

## Priority

Aktualna kolejność zabezpieczeń jest następująca:

1. **Semafor** — nadrzędny system sterowania ruchem.
2. **Kolizja** — awaryjne zatrzymanie, gdy brak semafora chroniącego przeszkodę.
3. **Stacja** — obsługa postoju pasażerskiego.

## Scope

To celowo nie jest pełny system bezpieczeństwa kolejowego. Poza zakresem pozostają:

- interlocking,
- rezerwacja przebiegów,
- realistyczne drogi hamowania przed innym pociągiem,
- ATP/ETCS,
- pełna detekcja składu na blokach,
- automatyczne zarządzanie pierwszeństwem pociągów.
