# 0.3.1 — Infrastructure degradation

## Added

- progressive infrastructure degradation;
- severe maintenance state at 95% wear;
- inspection requirement and operational condition helpers on `TrackCell`;
- recommended speed and axle-load multipliers;
- maintenance priority scoring;
- filtered maintenance reports by state;
- most-urgent-track query;
- dedicated repair commands for critical and severe infrastructure.

## Changed

- high-wear infrastructure degrades faster instead of remaining linear;
- map saves are stamped `0.3.1` while retaining map schema 3;
- maintenance APIs are ready for future movement constraints without taking ownership of train control.

## Compatibility

No map schema migration. Existing schema-3 saves remain readable.

## Not yet automatic

Recommended speed/axle-load reductions are domain data in 0.3.1. Automatic enforcement by train movement and automatic track closure remain later work.
