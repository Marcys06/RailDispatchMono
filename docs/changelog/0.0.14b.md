# 0.0.14b

## Naprawa menu trasy wagonu

- Naprawiono natychmiastowe zamykanie `WagonRouteMenu` po otwarciu przez `S` + LPM.
- Przyczyną był warunek obsługi kliknięcia poza menu: kursor pozostawał w miejscu wagonu, czyli przed otwartym menu, i następna klatka traktowała to jako kliknięcie poza panelem.
- Menu pozostaje teraz otwarte po otwarciu i reaguje na przyciski stacji.
- PPM nadal zamyka menu.

## Stacje

- Potwierdzono zachowanie budowania stacji przez `TrackBuildMode.Station`.
- `5` / `NumPad5` przełącza tryb budowy stacji.
- `R` zmienia rozmiar stacji: `1x1`, `2x2`, `3x3`, `4x4`.
- LPM buduje stację tylko wtedy, gdy wszystkie wymagane pola zawierają tor i nie kolidują z istniejącą stacją.
- Stacje są dostępne w `StationController.Stations`, więc menu trasy wagonu może dodawać je bezpośrednio do trasy.

## Rozkłady

- Mechanizm zapisu JSON pozostaje aktywny jako przygotowanie do pełnego systemu rozkładów.
- Zmiana trasy wagonu zapisuje aktualny rozkład pociągu do pliku JSON.
- Na tym etapie pliki są zapisywane, ale rozkłady nie są jeszcze automatycznie ładowane i wykonywane przez symulację.
