# 0.1.2j — Final Myra integration and pause-resume lifecycle fix

**Data:** 2026-09-01

## Cel

Zamknięcie migracji aplikacyjnego UI do Myra w linii `0.1.2x` oraz usunięcie ostatniego znanego problemu z wznowieniem gry z Myra Pause Menu.

## Zmiany

### Pause / Resume

- `WZNÓW GRĘ` poprawnie kończy stan `_isPaused` w `GameplayScreen`.
- `GameplayScreen.ResumeGame()` usuwa dokładnie instancję `PauseScreen`, która otworzyła pauzę.
- `PauseScreen.ResumeFromMyra()` wywołuje wyłącznie `OnResume`; nie wykonuje dodatkowego `ExitScreen()`.
- `ESC` i controller cancel korzystają z tego samego logicznego mechanizmu wznowienia.
- Zapobiega to podwójnemu sterowaniu lifecycle podczas callbacku z Myra `Desktop`.

### Myra

- Main Menu, Settings, About i Pause są powierzchniami Myra.
- `MyraUIManager` pozostaje jedynym właścicielem współdzielonego `Desktop` i integracji `MyraEnvironment.Game`.
- Screen lifecycle nadal należy do `ScreenManager`.
- Aktywny ekran czyści root Myra podczas `UnloadContent()`.
- Gameplay HUD, renderer torów i radialne narzędzia gameplay nie są migrowane bez osobnego celu projektowego.

### Save / Load

- Save/Load pozostają wyłącznie w `MyraPauseView`.
- Gameplay HUD nie posiada drugiego zestawu przycisków persistence.
- Po zapisie Load może zostać aktywowany bez zamykania menu pauzy.

## Granica wydania

`0.1.2j` jest **ostatnim etapem migracji Myra w serii `0.1.2x`**. Kolejne zmiany wersji `0.1.2x` nie powinny rozszerzać ani przebudowywać integracji Myra. Jeżeli przyszłe wymagania będą wymagały zmian w UI Myra, należy otworzyć osobny cel wydaniowy.
