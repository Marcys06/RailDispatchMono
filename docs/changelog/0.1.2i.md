# 0.1.2i — Full Myra pause surface and UI consolidation

**Data:** 2026-09-01

## Changes

- `PauseScreen` został odłączony od legacy `MenuScreen` i `MenuEntry`.
- Widoczna pauza jest w 100% obsługiwana przez `MyraPauseView`.
- `ESC` i controller cancel nadal wznowiają grę przez `PauseScreen`.
- `ZAPISZ GRĘ` i `WCZYTAJ GRĘ` pozostają wyłącznie w Myra Pause Menu.
- Save/Load nadal trafiają do `GameplayScreen`, a następnie do `MapSaveService` i aktywnego save slotu.
- Usunięto możliwość utworzenia drugiej widocznej legacy powierzchni pauzy.
- Audyt Gameplay HUD potwierdza, że Save/Load nie są częścią jego widocznych kontrolek.
- Myra pozostaje ograniczona do standardowego application/menu UI; renderer torów, HUD gameplay i radialne narzędzia budowania pozostają bezpośrednim renderingiem MonoGame.
- Zaktualizowano `docs/00-index.md`, `docs/11-ai-agent-rules.md`, `docs/15-ai-context.md`, `docs/16-screens-and-ui.md` oraz current-state snapshot.

## Persistence contract

`MapSaveService` pozostaje pojedynczym punktem wejścia dla zapisu mapy/infrastruktury. Przy aktywnym slocie zapisuje również runtime persistence, a odczyt przywraca zapisany stan runtime przez `RuntimeSaveService`.

## Verification checklist

- Build Core/DesktopGL.
- Uruchomić grę i wejść do gameplay.
- Nacisnąć `ESC`: pojawia się jedno, wyśrodkowane Myra Pause Menu.
- `ZAPISZ GRĘ`: zapis aktywnego slotu.
- Zmienić stan mapy i użyć `WCZYTAJ GRĘ`: stan zostaje przywrócony.
- `WZNÓW GRĘ` usuwa root Myra pauzy.
- W gameplay nie pojawia się żaden drugi Save/Load HUD.

## Stage discipline

`0.1.2i` jest osobnym, kolejnym etapem. Nie nadpisuje `0.1.2h`; ewentualne problemy wykryte podczas testów trafiają do `0.1.2j`.
