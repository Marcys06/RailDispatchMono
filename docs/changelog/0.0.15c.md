# 0.0.15c — Save/Load w menu pauzy

## Zmiany

- Usunięto przyciski `SAVE` i `LOAD` z głównego HUD.
- `SAVE GAME` i `LOAD GAME` są dostępne w menu pauzy.
- Skróty `F6` i `F7` pozostają dostępne.
- `map.json` korzysta ze wspólnego `DepotController` używanego przez gameplay i system zapisu.
- Uporządkowano i sformatowano `GameplayScreen.cs` — usunięto wcześniejsze jednolinijkowe formatowanie klasy.
- Zachowano istniejącą obsługę mapy, pociągów, stacji, sygnałów i depotów.

## Zakres save

`0.0.15c` zapisuje i wczytuje wyłącznie infrastrukturę mapy przez `map.json`.

Persistence pociągów, wagonów, rozkładów, pozostałego stanu świata i ekonomii pozostaje kolejnym etapem przed `0.1.0`.
