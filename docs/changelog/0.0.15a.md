# [0.0.15a] — Fundament persistence

**Data:** 2026-08-31

## Save architecture

- Rozpoczęto implementację systemu zapisu stanu gry w JSON.
- Persistence jest projektowane jako kilka niezależnych plików, które w przyszłości mogą zostać scalone w jeden system save.
- Docelowe obszary danych:
  - mapa,
  - pociągi i wagony,
  - rozkłady,
  - pozostałe informacje świata,
  - ekonomia.
- Ekonomia pozostaje na tym etapie pustym obszarem przygotowanym pod przyszłą implementację.

## Current scope

- Pierwszym zaimplementowanym obszarem persistence jest infrastruktura mapy.
- Pociągi, wagony i pełne rozkłady nie są jeszcze częścią jednego kompletnego save'a.
- Format JSON został wybrany jako podstawowy format trwałych danych.
