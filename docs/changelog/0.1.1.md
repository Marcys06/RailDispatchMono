# 0.1.1 — Documentation restructuring

**Date:** 2026-08-31

`0.1.1` restructures the documentation after the `0.1.0` gameplay baseline. It does not introduce new gameplay functionality.

## Changes

- Reduced the active root `docs/` set to 20 authoritative documents.
- Removed obsolete current-state snapshots and one-off audit/bug documents.
- Removed redundant `architecture.json`; architecture is documented in Markdown.
- Added `19-current-state-0.1.1.md` as the authoritative current-state snapshot.
- Kept detailed release history in `docs/changelog/` and `CHANGELOG.md`.
- Updated `00-index.md` with the new structure and version policy.

## Maintenance

Active documentation describes the current system. Historical implementation details belong in changelog history. Future changes should update the relevant active document instead of creating another dated snapshot unless a historical record is specifically required.
