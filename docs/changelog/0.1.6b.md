# 0.1.6b — Wagon-based passenger ownership

## Cel

Ustalenie wagonu jako stabilnej jednostki transportowej pasażera. Pasażer nie przechowuje już identyfikatora aktualnego pociągu.

## Zmiany

- `Passenger` przechowuje `CurrentWagonId` zamiast `CurrentTrainId`.
- `Wagon.TryBoard(...)` przypisuje pasażera do konkretnego `Wagon.Id`.
- `Wagon.TryAlightAt(...)` nie wymaga identyfikatora pociągu.
- `PassengerManager.GetOnBoard(Wagon)` pozwala odpytywać pasażerów bezpośrednio przez wagon.
- `PassengerManager.GetOnBoard(Train)` jest tylko widokiem operacyjnym złożonym z wagonów aktualnie należących do składu.
- `DefaultPassengerService` ustala liczbę pasażerów wysiadających na podstawie wagonów, a nie `TrainId` pasażera.
- Przy boardingu odrzucenie pasażera przez jeden wagon nie przerywa szukania odpowiedniego wagonu w dalszej części składu.

## Coupling / decoupling

Przypisanie pasażera do wagonu nie jest zmieniane podczas coupling ani decoupling. Jeżeli wagon zostanie odłączony od jednego składu i dołączony do innego, pasażerowie pozostają przypisani do tego samego `Wagon.Id`.

`Train` pozostaje kontekstem operacyjnej obsługi stacji, ale nie jest trwałą własnością podróży pasażera.

## Zakres poza 0.1.6b

- przesiadki pasażerów,
- wieloetapowe `PassengerJourney`,
- ekonomia,
- nowe modele popytu,
- zmiana istniejącego systemu tras wagonów.
