# 0.2.5 — Named railway lines and bulk infrastructure editing

## Added

- F11 named railway line editor.
- Multi-track selection directly on the map:
  - LPM — replace selection with one track;
  - Shift+LPM — add a track;
  - Ctrl+LPM — toggle a track in the selection.
- Named `RailwayLine` groups with stable IDs and display color index.
- Bulk application of `TrackType`, `LineClass` and `TractionSystem` to either the current selection or the selected named line.
- Adding/removing the current map selection from an existing named line.
- Connected-area selection using the existing track topology.
- Map visualization of named lines as colored contours while traction remains the base track color.
- White contour for the active multi-track selection.
- Persistence of named lines in map save schema 3.

## Design constraints

- Railway lines are organizational/infrastructure metadata only.
- They do not replace blocks, signals, switches, routes or timetable logic.
- Bulk editing does not automatically repair routes or change dispatcher behavior.
- Removing a track automatically removes that position from all named lines.
- Economics remain outside 0.2.5.

## Controls

- `F6` — Wymuś przejazd.
- `F8` — editor pojedynczego segmentu infrastruktury.
- `F9` — edytor rozkładu lokomotywy.
- `F10` — diagnostyka infrastruktury/ruchu.
- `F11` — edytor nazwanych linii.

## Verification

No Windows build or live gameplay verification was executed in this change set. The implementation should be compiled and exercised before treating 0.2.5 as runtime-verified.
