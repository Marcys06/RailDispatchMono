# 0.1.2a — Myra UI integration foundation

**Date:** 2026-09-01

## Scope

First implementation stage of the `0.1.2` Myra UI integration series.

## Changes

- Added the standard `Myra` NuGet package, version `1.6.5`, to `RailDispatchMono.Core`.
- Added `MyraUIManager` as the single Core integration boundary for Myra initialization and the shared `Desktop`.
- Initialized `MyraEnvironment.Game` from `RailDispatchMonoGame.LoadContent()`.
- Kept `ScreenManager` as the authoritative screen lifecycle and input-routing system.
- Did not migrate existing screens or introduce a global Myra render pass yet.
- Updated active architecture, AI rules, code index, current-state and maintenance documentation.

## Deliberate omissions

- Main Menu migration is deferred.
- Settings migration is deferred.
- Pause migration is deferred.
- Myra dialogs are deferred.
- No parallel input system was introduced.

## Stage discipline

`0.1.2a` is immutable after commit. Build/runtime defects found during testing must be corrected in `0.1.2b` or a later lettered stage.
