# 0.1.4i

## Rolling-stock labels

- Restored the train renderer's vehicle-label font binding in `GameplayScreen`.
- Restored centered white labels for every visible rolling-stock unit.
- Locomotive labels use `EP07`, `EU200` and `SU42`.
- Passenger coaches use `1KL`, `2KL` and `3KL`.
- Label rotation is normalized so labels remain readable in both travel directions.

## Depot building

- Reworked `DepotRenderer` to use world-space coordinates under the existing camera transform, matching the station rendering contract.
- Depot now has a visible 1x1-cell building footprint, outline, roof/door details and placement preview.
- Removed the previous screen-pixel coordinate assumption from depot world rendering.

## Coupling/decoupling preparation

- Added `CouplerType` and `CouplingSpecification` as static rolling-stock metadata.
- `Vehicle.Coupling` exposes front/rear coupling interface information.
- Default rolling stock uses screw couplers at both ends.
- No runtime coupling state or coupling/decoupling mechanics are implemented yet.
- Runtime connection state, compatibility checks, consist mutation and persistence are explicitly deferred to 0.1.5.

## Documentation

- Updated `docs/07-game-domain.md` with the coupling ownership boundary.
- Updated `docs/15-ai-context.md` for the 0.1.4i state and 0.1.5 coupling plan.
- Updated `docs/16-screens-and-ui.md` with train-label and depot-rendering contracts.

## 0.1.5 boundary

The next stage can implement coupling/decoupling on top of the existing ordered `TrainComposition` without introducing a second vehicle collection. UI should remain a caller of train-domain operations rather than directly mutating the vehicle list.
