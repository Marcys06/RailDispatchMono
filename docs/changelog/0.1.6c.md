# 0.1.6c — Wagon-aware passenger boarding

## Cel

Rozszerzenie istniejącego systemu pasażerskiego tak, aby konkretny wagon był stabilną jednostką przewozową pasażera. Pociąg pozostaje jedynie bieżącym kontekstem operacyjnym.

## Zmiany

- Boarding jest wykonywany względem konkretnego `Wagon`.
- Wagon sprawdza przy boardingu bieżącą stację oraz własną `TrainRoute`.
- Skonfigurowany wagon przyjmuje pasażera tylko wtedy, gdy jego trasa jest aktualnie na danej stacji i obejmuje stację docelową pasażera.
- Pasażer zachowuje `CurrentWagonId`; coupling i decoupling nie powodują migracji pasażerów.
- `PassengerManager.GetOnBoard(Train)` pozostaje tylko widokiem pasażerów znajdujących się w wagonach aktualnego składu.
- Przywracanie pasażerów z zapisu korzysta bezpośrednio z konkretnego wagonu.
- Naprawiono kompilacyjny błąd po zmianie API `Wagon.TryBoard`.

## Kompatybilność

- Nie zmieniono formatu tras wagonów.
- Nie zmieniono mechaniki coupling/decoupling.
- Nie dodano systemu wyboru pociągu przez pasażera.
- Nie dodano ekonomii ani przesiadek.
- Puste trasy wagonów zachowują dotychczasową kompatybilność z istniejącymi konfiguracjami.
