# [0.0.13pre] — Debug, dokumentacja i przyspieszenie zegara

Data: 2026-08-31

## Debug
- Globalny limit maksymalnie 30 komunikatów debugowania na sekundę.
- Nadmiarowe komunikaty są odrzucane bez kolejki.

## Game Clock
- Przy x1 5 sekund czasu gry = 1 sekunda rzeczywista.
- x2 i x5 dodatkowo mnożą tempo zegara.
- Pauza zatrzymuje zegar i symulację.
- Bazowe 5× nie zmienia fizycznej prędkości ani dystansu pociągów.

## Documentation
- Ujednolicono dokumentację do jednego katalogu `docs/`.
- Dodano `docs/changelog/` jako jedyne miejsce historycznych changelogów.
- Przeniesiono dokumentację stacji i pasażerów do `docs/`.
