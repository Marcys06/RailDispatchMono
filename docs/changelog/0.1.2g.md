# 0.1.2g — Myra menu migration and persistence UI consolidation

**Date:** 2026-09-01

- Migrated `SettingsScreen` to the shared Myra presentation layer.
- Migrated `AboutScreen` to the shared Myra presentation layer.
- Added `MyraSettingsView` and `MyraAboutView`.
- Settings actions remain owned by `SettingsScreen`; Myra is only the presentation/input surface.
- About browser launch remains owned by `AboutScreen`.
- Pause menu remains the functional owner of gameplay save/load actions through `OnSave` and `OnLoad`.
- The main menu continues to expose only New Game, Settings, About and Quit.
- The existing legacy in-game save/load HUD path is scheduled for removal from `InputManager` as part of the same UI consolidation and must not become a second persistence entry point.
- The `IsEnabled`/`Enabled` Myra API correction from the developer-side hotfix is treated as the current baseline.

## UI ownership

`ScreenManager` remains the lifecycle owner. `MyraUIManager` owns the shared Myra `Desktop`. Individual screens own their actions and install a Myra root while active.
