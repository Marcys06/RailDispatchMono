# 0.1.4pre

**Date:** 2026-09-03

## Consolidation

`0.1.4pre` is the consolidated documentation and development milestone for the `0.1.4` line. The lettered `0.1.4a`–`0.1.4i` stages remain historical records and are not rewritten.

## Rolling stock

- Added catalogue-driven rolling stock definitions for `EP07`, `EU200 — Newag Griffin E4ACP` and `SU42`.
- Added three passenger coach variants with short labels `1KL`, `2KL`, `3KL`.
- Added locomotive `PowerMW` through `LocomotiveParameters`.
- Added differentiated rolling-stock rendering and centered white short labels.
- Normalized label rotation so labels remain readable in both travel directions.

## Train performance

- Applied the non-linear consist-mass factor with exponent `1.30` to locomotive acceleration and braking.
- Added the power/load Vmax model using `0.006 MW/t` and exponent `0.55`.
- Preserved the calibrated EU200 and SU42 heavy-consist behavior from the lettered development stages.

## Safety and braking

- Signal `Stop` / `StopStation` braking now uses the same effective consist braking capability as train movement.
- Restricted signal aspects use effective braking when determining whether enough distance remains to reduce speed.
- RadioStop retains a 3-cell minimum and expands with speed using effective braking distance, `0.15 s` reaction distance and a `0.8`-cell buffer.
- Preserved the `0.8`-cell Stop offset and leading-vehicle physical half-length correction.

## Depot and UI

- Reworked `DepotRenderer` to use world-space coordinates under the existing camera transform.
- Added a visible 1x1-cell Depot footprint, outline/entrance details and placement preview.
- Consolidated Depot train creation around `DepotScreen` + `MyraDepotView` + `TrainManager.CreateTrainFromComposition()`.
- Kept a single shared Myra `Desktop` through `MyraUIManager`.
- Kept pause as `GameplayScreen` state with `MyraPauseView`, not as a popup screen.

## Persistence and diagnostics

- Runtime save/load now persists rolling-stock `ShortName` values while retaining save schema version `1`.
- Existing saves without `ShortName` remain deserializable.
- Updated runtime loading to the current `Locomotive` and `Wagon` constructor signatures.
- Train movement diagnostics now include the first eight characters of the active train GUID in `[TRAIN:<id>]` messages.

## Coupling preparation

- Added static `CouplerType` / `CouplingSpecification` metadata and `Vehicle.Coupling` front/rear interfaces.
- Default rolling stock exposes screw couplers at both ends.
- Runtime coupling state, detection, compatibility, merge/split, forces/slack and connection persistence remain deferred to `0.1.5`.

## Documentation

- Consolidated the maintained documentation baseline on `0.1.4pre`.
- Updated architecture, screen, input, game-domain, known-issues, code-index, documentation-maintenance, AI-context and screens/UI documents.
- Added `docs/21-current-state-0.1.4pre.md` as the authoritative consolidated snapshot.
- Historical `0.1.2pre` and `0.1.3pre` snapshots remain preserved.

## Verification boundary

The repository documentation has been updated to match the current source-level contracts. A local `dotnet build` has not been executed in this editing session; the user's working local build remains the authoritative compilation check.
