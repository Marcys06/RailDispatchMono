# 0.1.3pre — Myra Gameplay UI stabilization

**Date:** 2026-09-01

This is the current pre-release documentation snapshot after the `0.1.3a`–`0.1.3e` Myra gameplay UI work and the latest developer bugfix.

## Completed

- Gameplay HUD migrated to Myra.
- Simulation clock migrated to Myra; legacy clock rendering removed.
- `GameDay` displayed by Myra.
- Simulation speed controls `x1`, `x2`, `x5` are Myra controls.
- Build tools are presented through a collapsible Myra panel.
- Train and station lists are presented through Myra only; the duplicate legacy HUD was removed.
- Station entries display waiting passenger counts.
- Selecting a train or station focuses the camera on the object's center.
- Main Menu → Gameplay Myra lifecycle was corrected so the menu does not clear the gameplay root.
- Pause was rebuilt around `GameplayScreen` state with `MyraPauseView` as the UI surface.

## Remaining legacy UI / planned migration

- World-specific radial menus for junctions/signals where still present.
- Legacy world tooltips where appropriate.
- Dedicated train/station detail windows beyond the list entries.
- Dedicated wagon-route detail/editor window beyond the existing workflow.
- Depot-specific interaction UI where applicable.
- More advanced train/station visual state and configurable colors.

These are intentionally tracked as remaining migrations rather than being marked complete merely because the Myra HUD exists.

## Version policy

`0.1.3pre` is the consolidated pre-release milestone. Further changes should normally be bugfixes/polish against this version unless a larger feature warrants a new release milestone.
