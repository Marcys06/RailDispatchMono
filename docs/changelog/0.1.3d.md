# 0.1.3d — Myra HUD migration cleanup

## Simulation speed

- Kept `x1`, `x2` and `x5` as three equal-width Myra buttons.
- Kept the controls directly below the simulation clock.
- All three controls continue to use the existing simulation-speed API.

## Trains and stations

- Completed the visual migration of the train/station object panel to `MyraGameplayView`.
- Removed the legacy SpriteBatch-rendered train/station panel from the gameplay HUD.
- Removed the legacy train/station panel mouse-hit handling from `GameplayScreen`.
- Myra is now the single presentation and interaction layer for the train/station lists.
- Train entries retain camera-centering behavior.
- Station entries retain waiting-passenger counts and camera-centering behavior.

## Other

- Existing Myra build tools and pause system were left unchanged because they are already working.
