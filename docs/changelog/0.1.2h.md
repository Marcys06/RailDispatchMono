# 0.1.2h — Myra Pause Input Fix

## Zmiany

- Naprawiono obsługę wejścia w `MyraUIManager` przez wywołanie `Desktop.Update(GameTime)`.
- Przyciski menu pauzy Myra są teraz aktywnie aktualizowane przez cykl MonoGame.
- Zachowano `PauseScreen` jako właściciela akcji `Resume`, `Save`, `Load` i `Quit`.
- Save/Load pozostają dostępne wyłącznie z menu pauzy jako docelowy interfejs użytkownika.

## Znane ograniczenie

- Legacy przyciski `SAVE`/`LOAD` renderowane przez `InputManager` w HUD gry wymagają osobnego usunięcia z legacy warstwy renderowania. Nie są już częścią docelowego interfejsu Myra.

## Status

`0.1.2h` jest kolejnym, niezależnym etapem naprawczym linii `0.1.2`. Poprzednie etapy pozostają niezmienione.
