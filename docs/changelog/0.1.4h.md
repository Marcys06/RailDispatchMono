# 0.1.4h — Speed-dependent braking and RadioStop safety

**Data:** 2026-09-03

## Problem fixed

After `0.1.4f` introduced the non-linear consist-mass penalty for acceleration/braking, the signal stopping calculation still used the raw strongest vehicle braking value. Heavy trains therefore required more distance to stop than the signal calculation expected and could pass a Stop semaphore slightly before reaching zero speed.

## Signal braking

- Signal `Stop` / `StopStation` braking now uses the locomotive braking capability multiplied by the same `1 / (totalMass / locomotiveMass)^1.30` factor used by `TrainMovement`.
- Speed-restricted signal aspects use the same effective braking capability when checking whether the available distance is sufficient.
- The existing `0.8`-cell stopping offset and physical leading-locomotive half-length correction remain in the Stop target calculation.
- The braking calculation therefore stays synchronized with the actual movement model instead of maintaining a second raw-braking model.

## RadioStop

`TrainCollisionController` previously used a fixed three-cell scan. It now keeps three cells as the minimum safety distance but expands the protected distance according to current speed:

`requiredSafetyDistance = max(3 cells, brakingDistance + reactionDistance + 0.8-cell buffer)`

Braking distance uses the train's effective consist braking rate. Reaction time remains `0.15 s`.

This makes RadioStop more conservative at high speed while preserving the existing three-cell minimum at low speed. A protecting matching signal still suppresses RadioStop when encountered before the conflicting train.

## Speed-dependent mechanics audit

The current speed-dependent chain is now aligned as follows:

- locomotive/wagon Vmax → `TrainComposition` effective Vmax;
- locomotive power + consist mass → power-limited Vmax;
- locomotive braking + consist mass → effective braking rate;
- signal Stop/StopStation → stopping speed profile using effective braking;
- signal speed restrictions → braking-distance check using effective braking;
- RadioStop → dynamic safety distance using effective braking;
- actual train movement → acceleration/braking using the same mass-dependent model.

Internal simulation speed remains m/s and the central spatial scale remains `1 cell = 10 m`.

## Documentation

Updated the game-domain and AI context documentation to describe the synchronized braking/safety model.

No `current-state` snapshot was created; `0.1.4h` is a lettered development stage.
