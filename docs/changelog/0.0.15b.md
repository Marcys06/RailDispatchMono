# [0.0.15b] — Map Save / Load

Data: 2026-08-31

## Save

- `map.json` zapisuje stan infrastruktury mapy.
- Zapisywane są tory, geometria, połączenia i stan rozjazdów.
- Zapisywane są semafory wraz z konfiguracją i stanem aspektu.
- Zapisywane są stacje i ich konfiguracja pasażerska.
- Zapisywane są depoty.
- Format posiada `schemaVersion`.
- Zapis korzysta z pliku tymczasowego przed podmianą właściwego pliku.

## Load

- Dodano odczyt `map.json`.
- Ładowanie odbudowuje obiekty infrastruktury z DTO.
- Stabilne GUID-y stacji, semaforów i depotów są zachowywane.
- Po wczytaniu odbudowywane są bloki torowe z semaforów.
- Stan pociągów i pasażerów jest resetowany przy ładowaniu mapy; ich persistence pozostaje poza zakresem `0.0.15b`.

## UI

- `SAVE` i `LOAD` są dostępne w lewym górnym rogu.
- Skróty: `F6` = Save, `F7` = Load.
- Wynik operacji jest chwilowo wyświetlany obok przycisków.

## Zakres

`0.0.15b` kończy pierwszy etap persistence: zapis i odczyt infrastruktury mapy. Pociągi, wagony, rozkłady i ekonomia pozostają osobnymi plikami do kolejnych etapów.
