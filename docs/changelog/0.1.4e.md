# 0.1.4e — Rolling stock and Depot train builder

**Data:** 2026-09-01

## Rolling stock

Added the first reusable rolling-stock catalogue under `Game/RollingStock`.

Locomotives:

- EP07 — electric, 125 km/h, 80 t, 16.2 m.
- EU200 — Newag Griffin E4ACP, electric AC, 200 km/h, 84 t, 19.9 m.
- SU42 — diesel, 90 km/h, 74 t, 14.4 m.

Passenger wagons:

- PassengerCoach — 40 t, 26.4 m, 160 km/h, capacity 80.
- PassengerCoach2 — 38 t, 26.4 m, 200 km/h, capacity 80.
- PassengerCoach3 — 42 t, 26.4 m, 160 km/h, capacity 96.

The locomotive acceleration/braking values are gameplay-scaled around the existing EU06-level response. They are not intended to be a full real-world traction model.

## Physical parameters

`VehicleParameters` now supports catalogue data expressed as km/h, m/s², tonnes and metres through `CreatePhysical()`.

Internal simulation speed remains m/s. Physical mass/length metadata is exposed separately from the established visual grid geometry, so the `1 cell = 10 m` scale does not shrink the existing vehicle visuals.

## Train composition

`TrainComposition` now exposes:

- `TotalMass`;
- `TotalLengthMeters`;
- `EffectiveMaxSpeed` / `EffectiveMaxSpeedKmh`;
- wagon count;
- selected locomotive;
- locomotive replacement;
- wagon addition/removal.

One locomotive is supported per `0.1.4e` consist. Zero or more wagons are allowed, so a locomotive-only train is valid.

## Depot

Added full-screen `DepotScreen` with `MyraDepotView`.

The builder supports:

- locomotive selection;
- wagon selection and append;
- individual wagon removal;
- clearing all wagons;
- live Vmax/mass/length/wagon-count summary;
- train creation;
- cancel without creating a train.

The Depot uses the existing single `MyraUIManager` and shared `Desktop`. It is a full `GameScreen`, not a popup and not a second UI system.

Created consists are passed to `TrainManager.CreateTrainFromComposition()` and spawned on an adjacent free track cell at the selected Depot.

## Gameplay integration

The previous hard-coded test train was removed from `GameplayScreen`. The development test track remains available on a new game so the Depot can be tested immediately.

`RadioStop`, semaphore logic, `BlockController` and `StationController` were not redesigned as part of this stage.
