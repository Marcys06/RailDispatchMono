# 0.1.3a — Myra Gameplay UI

## Zakres

`0.1.3a` rozpoczyna migrację Myra z warstwy menu aplikacyjnego do właściwego gameplay UI.

## Gameplay HUD

- Dodano Myra HUD dla aktywnej rozgrywki.
- Zegar symulacji pokazuje aktualny czas.
- Dodano `GameDay` jako osobną informację HUD.
- Dodano przyciski prędkości `x1`, `x2`, `x5`.
- HUD odświeża dane list co około 0,5 s.

## Pociągi

- Dodano listę aktywnych pociągów.
- Element listy pokazuje identyfikator i bieżącą prędkość.
- Kliknięcie jest podłączone do centrowania kamery.

## Stacje

- Dodano listę stacji.
- Przy stacji pokazywana jest liczba oczekujących pasażerów.
- Kliknięcie jest podłączone do centrowania kamery.

## Narzędzia budowania

Dodano panel Myra dla:

- toru prostego,
- zakrętu,
- rozjazdu,
- semafora,
- stacji,
- depotu,
- edycji trasy wagonu.

Istniejące skróty klawiaturowe pozostają aktywne.

## Architektura

- Myra pozostaje warstwą prezentacji.
- Stan symulacji nadal należy do istniejących klas gameplayu.
- Akcje z Myra są kolejkowane przez `MyraUIManager`, aby nie wykonywać mutacji gameplayu w fazie `Desktop.Render()`.
- HUD jest montowany jako główny root Myra podczas rozgrywki.
- Menu pauzy nadal może tymczasowo zastąpić root HUD i po wznowieniu wrócić do widoku gameplay.

## Uwagi

`0.1.3a` jest dużym etapem funkcjonalnym zgodnie z polityką tej serii. Kolejne wersje `0.1.3x` powinny służyć przede wszystkim stabilizacji, poprawkom i domknięciu brakujących elementów UI, zamiast ponownego dzielenia zakresu na wiele małych etapów.
