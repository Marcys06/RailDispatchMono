# 0.1.3a — Myra Gameplay UI

## Zakres

`0.1.3a` rozpoczyna migrację Myra z warstwy menu aplikacyjnego do właściwego gameplay UI. Jest to duży etap funkcjonalny; kolejne wersje mają być przede wszystkim bugfixami i stabilizacją.

## Gameplay HUD

- Dodano `MyraGameplayView` jako aktywną warstwę HUD podczas rozgrywki.
- Zegar symulacji został zmigrowany do Myra.
- `GameDay` jest prezentowany obok czasu i jest przygotowany pod przyszłe rozkłady jazdy.
- Dodano przyciski prędkości `x1`, `x2`, `x5`.
- Usunięto poprzedni, ręcznie rysowany przez `SpriteBatch` zegar i przyciski prędkości z `GameplayScreen`.
- HUD odświeża dynamiczne dane list około co 0,5 s.

## Pociągi

- Dodano listę aktywnych pociągów w Myra.
- Element listy pokazuje identyfikator i bieżącą prędkość.
- Kliknięcie elementu jest podłączone do centrowania kamery.

## Stacje

- Dodano listę stacji w Myra.
- Przy stacji pokazywana jest liczba oczekujących pasażerów.
- Kliknięcie elementu jest podłączone do centrowania kamery.

## Narzędzia budowania

Dodano panel Myra dla:

- toru prostego,
- zakrętu,
- rozjazdu,
- semafora,
- stacji,
- depotu,
- edycji trasy wagonu.

Istniejące skróty klawiaturowe pozostają aktywne.

## Menu główne → gameplay

Naprawiono lifecycle wspólnego Myra `Desktop` podczas przejścia z menu głównego do gry.

`MainMenuScreen.UnloadContent()` czyści wspólny root Myra, dlatego menu musi zostać usunięte ze `ScreenManager` **przed** zainstalowaniem `MyraGameplayView`. W przeciwnym przypadku cleanup menu usuwał świeżo utworzony HUD gameplayu.

Aktualny przepływ:

```text
Main Menu
    ↓
StartGameplay()
    ↓
Remove MainMenuScreen
    ↓
Create/Add GameplayScreen
    ↓
Create MyraGameplayView
    ↓
SetRoot(Gameplay HUD)
```

## Architektura

- Myra pozostaje warstwą prezentacji.
- Stan symulacji nadal należy do istniejących klas gameplayu.
- Akcje z Myra są kolejkowane przez `MyraUIManager`, aby mutacje gameplayu nie były wykonywane w fazie `Desktop.Render()`.
- HUD jest montowany jako główny root Myra podczas rozgrywki.
- Menu pauzy może tymczasowo zastąpić root HUD i po wznowieniu przywrócić właściwy stan UI.
- Zegar nie posiada już równoległej implementacji renderowania w `GameplayScreen`.

## Stan

Build projektu został potwierdzony przez developera jako działający. Menu główne przechodzi do gameplayu, a menu pauzy działa poprawnie.

Pozostałe planowane elementy mogą być rozwijane w kolejnych bugfix/stabilization commits bez rozbijania dużego zakresu `0.1.3a` na wiele wersji funkcyjnych.
