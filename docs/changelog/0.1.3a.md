# 0.1.3a — Myra Gameplay UI

`0.1.3a` is the large gameplay-UI milestone. Follow-up work is kept in the `0.1.3x` series for bugfixes, polish and completion of remaining migrations.

## Gameplay HUD

- Added `MyraGameplayView` as the gameplay HUD root.
- Simulation clock and `GameDay` are presented by Myra.
- Added working `x1`, `x2`, `x5` simulation speed controls.
- Removed the legacy SpriteBatch clock/speed presentation.
- Dynamic train/station data is refreshed periodically.

## Trains and stations

- Added Myra train list with speed information and camera-focus action.
- Added Myra station list with waiting-passenger count and camera-focus action.
- The information area is intended to remain a dedicated right-side gameplay panel.

## Build tools

- Added Myra controls for straight track, curve, junction, signal, station, depot and wagon-route editing.
- Keyboard shortcuts remain available as an additional input path.

## Architecture

- Myra owns application/gameplay UI presentation.
- Simulation, camera and building state remain owned by gameplay systems.
- Gameplay actions from Myra continue to use the safe UI-action dispatch path rather than mutating gameplay during Myra rendering.
- Pause remains a `GameplayScreen`-owned state and is not reverted to the old popup-screen architecture.

## Remaining planned migrations

The following are not claimed as complete merely because supporting UI exists:

- dedicated train information window,
- dedicated station information window,
- wagon-route information/editor window,
- Myra replacement for the junction radial menu,
- Myra replacement for the signal radial menu,
- richer visual state/color coding for trains and stations.
