# 0.1.7c

## Gameplay HUD

- Added a `WAGONY` panel on the right side of the gameplay HUD, alongside `POCIĄGI` and `STACJE`.
- Wagons are displayed using the same clickable list-button presentation as trains.
- Each wagon entry shows:
  - wagon short name;
  - current timetable delay;
  - passenger occupancy as `current/capacity` and percentage.
- Wagons without an assigned timetable show `opóźnienie: —`.
- Selecting a wagon entry focuses its containing train.

## Version

- Runtime save metadata now identifies the game as `0.1.7c`.
- Save schema remains `2`.
