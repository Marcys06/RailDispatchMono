# 0.1.3b — Gameplay HUD layout polish

## Cel

`0.1.3b` jest małym etapem wizualnym po dużej migracji `0.1.3a`. Nie zmienia architektury gameplayu ani systemu pauzy.

## Zmiany

- Panel narzędzi budowania jest teraz rozwijany i zwijany jednym przyciskiem Myra.
- Narzędzia nie zajmują stale miejsca w HUD, gdy nie są potrzebne.
- Przyciski `x1`, `x2`, `x5` zostały przeniesione do dolnego prawego rogu.
- Sterowanie prędkością nadal korzysta z istniejącego `GameClock`.
- Poprawiono szerokości, odstępy i wyrównanie głównych sekcji HUD.
- Zegar i `GameDay` pozostawiono bez większych zmian, ponieważ ich obecny wygląd jest wystarczający.
- Lista pociągów i stacji zachowuje dotychczasowe działanie.

## Architektura

Myra nadal jest warstwą prezentacji. Kliknięcia przycisków przekazują akcje do istniejących systemów gameplayu przez `MyraUIManager`.

## Następny etap

Kolejne wersje `0.1.3x` powinny koncentrować się na błędach, dalszym polishu i brakujących oknach obiektów, zamiast dzielić każdy element na osobną wersję funkcjonalną.
