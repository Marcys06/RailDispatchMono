# 0.1.2f — Myra pause menu and main-menu layout

**Date:** 2026-09-01

## Scope

Continue the accelerated Myra migration by correcting the main-menu layout and moving the load action out of the startup menu. The gameplay pause menu is now presented by Myra.

## Changes

- Centered the Myra Main Menu horizontally and vertically in the viewport.
- Removed `WCZYTAJ GRĘ` from the startup Main Menu.
- Kept `NOWA GRA`, `USTAWIENIA`, `O GRZE` and `WYJDŹ` on the startup menu.
- Added `MyraPauseView` using standard Myra widgets.
- Migrated the visible `PauseScreen` menu to Myra.
- Kept save/load actions in the pause menu rather than the startup menu.
- Preserved `PauseScreen` as the owner of pause state, persistence callbacks and screen lifecycle.
- Preserved legacy keyboard/controller handling, including `ESC`, while Myra owns visible pointer interaction.
- Cleared the shared Myra root when the pause screen unloads.
- Removed the old pause overlay rendering path from `PauseScreen`; the Myra desktop is rendered by the game host.

## Intentional compatibility

`ScreenManager`, `MenuScreen`, `MenuEntry`, `GameplayScreen` and persistence services remain authoritative for lifecycle and game state. Myra is the presentation layer for the migrated menu surfaces.

## Stage discipline

`0.1.2a` through `0.1.2e` remain immutable. This stage contains the correction for the startup menu layout and the next accelerated migration step. Future defects are corrected in the next lettered stage.
