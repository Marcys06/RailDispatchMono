# [0.0.13] — Tworzenie tras wagonów

Data: 2026-08-31

## Wagon Routes

- Dodano `TrainRoute` jako osobny, JSON-ready obiekt trasy przypisany do konkretnego wagonu.
- Trasa jest uporządkowaną listą stacji (`StationIds`) i posiada indeks aktualnego przystanku.
- Wagon może mieć pustą trasę; oznacza to brak ręcznie skonfigurowanej trasy.
- Po osiągnięciu stacji trasa zapamiętuje aktualny punkt.
- Po zakończeniu trasy wagon pozostaje bez kolejnego celu do czasu otrzymania nowej konfiguracji.
- Trasa nie steruje ruchem lokomotywy. Lokomotywa nadal jedzie zgodnie z semaforami i ustawieniem rozjazdów.

## Passenger Integration

- `Wagon` korzysta bezpośrednio z `TrainRoute`.
- Jeżeli wagon ma skonfigurowaną trasę, pasażer może wejść do niego tylko wtedy, gdy jego stacja docelowa znajduje się na trasie wagonu.
- Pusty route zachowuje dotychczasowe zachowanie testowych składów i pozwala na przyjmowanie pasażerów.
- Po wysiadaniu na stacji wagon aktualizuje bieżący punkt swojej trasy.
- Model nadal zakłada osobną obsługę pasażerów przez każdy wagon, co przygotowuje system pod coupling/decoupling.

## Wagon Route UI

- Hover nad konkretnym wagonem pokazuje rozszerzony tooltip z informacją o trasie.
- LPM na wagonie otwiera menu edycji jego trasy.
- Menu pozwala:
  - dodawać kolejne stacje,
  - usuwać stacje,
  - wyczyścić całą trasę,
  - podejrzeć liczbę przystanków i aktualny punkt trasy.
- UI wykorzystuje istniejący mechanizm generowania grafiki (`SpriteBatch`, pojedynczy pixel texture i `SpriteFont`); nie dodano nowych assetów graficznych.

## Save Preparation

`TrainRoute` posiada publiczny model danych przygotowany do serializacji przez `System.Text.Json` oraz metody `ToJson()` / `FromJson()`.

Na tym etapie trasy nie są jeszcze zapisywane automatycznie do plików. Jest to przygotowanie pod przyszły system zapisu rozkładów i konfiguracji w JSON.

## Scope

Poza zakresem `0.0.13` pozostają:

- automatyczne planowanie trasy lokomotywy,
- rozkłady jazdy,
- coupling/decoupling,
- przesiadki pasażerów,
- zapis całej mapy do pliku.
