# 0.2.3 — Operational Dispatcher UI

**Data:** 2026-09-06

## HUD

- Train list now shows `AUTO` / `RĘCZ`, current timetable point and delay.
- Selected train panel shows current point, next point, ETA, required departure, delay and dispatcher state.
- Added selected-train actions for dispatcher override, route release and AUTO/RĘCZ switching.
- Added compact operational notifications derived from dispatcher/timetable state.

## Dispatcher

- FCFS requests now retain requested block and request timestamp.
- FCFS ordering is local to the requested block instead of globally serialising unrelated blocks.
- Added F6 dispatcher override through `RailwayDispatcher.ForceProceed`.
- Override bypasses dispatcher arbitration only; physical block occupancy, signals and switches remain authoritative.
- Added wait-time information for pending dispatcher requests.

## F10 diagnostics

- Added per-request target block and wait time.
- Added block occupancy/reservation owner information.
- Added signal aspect and associated block information.
- Added safe dispatcher actions: force proceed and release dispatcher route.
- Release operates through `RailwayDispatcher`, not direct block-state mutation.

## Controls

- F6 is now the explicit manual dispatcher override.
- F9 remains locomotive timetable editing.
- F10 remains infrastructure diagnostics.
- AUTO/RĘCZ switching does not delete the locomotive timetable.

## Player responsibility

- Switches and signal aspects remain player-controlled.
- F6 does not teleport trains or clear physical occupancy.
- Coupling/decoupling and RadioStop semantics remain unchanged.

## Documentation

- Added `docs/30-current-state-0.2.3.md`.
- Documentation/UI baseline moved to 0.2.3.
