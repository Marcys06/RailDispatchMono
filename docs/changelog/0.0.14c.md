# [0.0.14c] — Stabilizacja edycji tras wagonów

Data: 2026-08-31

## Wagon route menu

- Naprawiono zamykanie menu trasy wagonu w pierwszym `Update()` po jego otwarciu.
- Pierwszy update po otwarciu jest konsumowany, dzięki czemu kliknięcie otwierające menu nie jest ponownie interpretowane jako kliknięcie wewnątrz lub poza menu.
- Kolejne **nowe kliknięcie LPM** jest obsługiwane jako akcja menu albo zamknięcie menu.
- **PPM** zamyka menu niezależnie od położenia kursora.
- Obsługa przycisków stacji jest niezależna: kliknięcie dodaje lub usuwa konkretną stację bez wykonywania kolejnej akcji w tym samym update.
- Przycisk czyszczenia trasy jest obsługiwany jako osobna akcja.
- Menu zachowuje pozycję ekranową i dopasowanie do bieżącego viewportu.

## Tryb edycji trasy

- Tryb edycji trasy wagonu jest aktywowany klawiszem `S`.
- W menu dodano mały aktywny przycisk `S` jako wizualne oznaczenie aktywnego trybu.
- `S + LPM` na wagonie otwiera edytor trasy tego wagonu.
- Zamknięcie trybu `S` zamyka również otwarte menu trasy.

## Persistence

- Zmiana trasy wagonu jest zapisywana przez istniejący `ScheduleStorage`.
- Edycja trasy nie zmienia fizycznego prowadzenia lokomotywy; ruch nadal pozostaje domeną torów, zwrotnic i semaforów.

## Zakres

To wydanie jest poprawką UX/input handling dla istniejącego systemu tras wagonów. Nie wprowadza automatycznego planowania drogi pociągu ani interlockingu.
