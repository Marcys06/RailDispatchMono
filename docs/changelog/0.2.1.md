# 0.2.1 — Myra gameplay HUD rebuild

**Data:** 2026-09-06

## Cel

Przebudowa całego gameplayowego HUD Myra tak, aby informacje i operacje były podporządkowane jednemu modelowi pracy dyspozytora zamiast kilku niezależnych paneli o niespójnych rozmiarach.

## Nowy układ

- górny pasek: czas gry, dzień, tempo symulacji i tryb pracy;
- lewy panel: operacje i narzędzia infrastruktury;
- środek: wybrany pociąg, timetable lokomotywy i diagnostyka;
- prawy panel: ruch, pociągi, stacje i status dispatchera;
- dolny panel: wagony oraz skrócony kontrakt sterowania.

## Dane operacyjne

HUD rozróżnia pociągi `AUTO` i `RĘCZ`, pokazuje bieżącą prędkość, Vmax składu, efektywny cel sygnałowy, kierunek oraz stan następnego bloku. Dla pociągów z timetable pokazuje punkt rozkładu, opóźnienie i wymagany odjazd.

Diagnostyka wybranego pociągu pokazuje również stan RadioStop, parametry składu i podstawowe dane ruchowe.

## Pasażerowie i wagony

Stacje pozostają kompaktową listą z rozwijanym rozbiciem kierunków pasażerów. Wagony pokazują zajętość i opóźnienie; istniejący tooltip zachowuje pełną trasę wagonu.

## Granice automatyzacji

HUD nie wykonuje za gracza decyzji dyspozytorskich. Nie steruje zwrotnicami, aspektami semaforów, sprzęganiem, rozprzęganiem, czyszczeniem RadioStop ani transferami pasażerów.

## Kompatybilność

Poprzedni układ HUD nie jest kompatybilnościowym celem 0.2.1. Sam HUD nie zmienia schematu zapisu gry.

## Dokumentacja

## Weryfikacja

Wymagany jest build Windows oraz test w grze przy standardowym oknie 1600×900 i po zmianie rozmiaru okna. Należy sprawdzić długie nazwy stacji, wiele pociągów/wagonów, rozwinięte listy pasażerów i panel diagnostyczny.
