# 0.1.3c — Myra Gameplay HUD Layout

## Layout

- Moved `x1`, `x2`, `x5` directly below the simulation clock.
- Moved the collapsible build-tools section below the clock.
- Added a dedicated right-side information area for trains and stations.
- Train and station entries use Myra widgets instead of legacy drawing.
- Station entries show the current waiting-passenger count.
- Kept camera-focus actions connected to train/station entries.
- Improved widths, spacing and alignment to reduce visual overlap.

## Status

This version is a HUD layout and Myra migration step. The remaining planned object-detail windows and radial-menu migrations are tracked for later `0.1.3x` work.
