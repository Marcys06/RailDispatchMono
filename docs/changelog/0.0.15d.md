# [0.0.15d] — Fix pause system and screen management

**Data:** 2026-08-31

## Pause system

- Poprawiono logikę przełączania pauzy w `GameplayScreen`.
- Dodano/ustabilizowano `TogglePause()` z jawnym zarządzaniem stanem.
- `ESC` przełącza stan pauzy zamiast tworzyć kolejne ekrany.
- Zabezpieczono przed wielokrotnym dokładaniem `PauseScreen`.

## Screen management

- Poprawiono obsługę `PauseScreen` jako ekranu popup.
- Uporządkowano indeksowanie i bezpieczeństwo zarządzania ekranami w `ScreenManager`.
- Poprawiono obsługę tekstury overlay pauzy i jej cyklu życia.

## Scope

Wersja jest poprawką systemu pauzy i zarządzania ekranami. Nie zmienia modelu zapisu mapy ani mechaniki pociągów.
