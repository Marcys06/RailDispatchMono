# 0.0.14a

## Trasy wagonów

- Edycja trasy wagonu została przeniesiona z bezpośredniego LPM na tryb aktywowany klawiszem `S` (Schedule).
- W trybie `S` LPM na konkretnym wagonie otwiera jego menu trasy.
- Zwykły LPM nadal pozostaje dostępny dla budowania torów i innych elementów.

## Zapisy rozkładów

- Dodano model `TrainSchedule` przygotowany pod trwałe rozkłady.
- Rozkład przechowuje osobne listy przystanków dla każdego wagonu.
- Dodano `ScheduleStorage` zapisujący rozkłady jako pliki JSON w katalogu `schedules` obok uruchomionej aplikacji.
- Zmiana trasy wagonu automatycznie aktualizuje plik rozkładu danego pociągu.

## Depot i zestawienia

- Kliknięcie istniejącego Depot otwiera menu wyboru zestawienia.
- Dostępne są trzy wstępne warianty: lokomotywa + 1, +2 lub +4 wagony pasażerskie.
- Po wyborze zestawienia gracz wskazuje tor, na którym pociąg ma zostać utworzony.
- Pociąg zachowuje połączenie z aktywnym `BlockController`.

## Przygotowanie pod 0.1.0+

- Format JSON jest celowo prosty i wersjonowany, aby można było później rozszerzyć go o rozkład jazdy, czasy odjazdów i kolejne dane pociągu bez zmiany podstawowego mechanizmu zapisu.
