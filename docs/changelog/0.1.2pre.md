# 0.1.2pre — Myra UI Stabilization Preview

**Data:** 2026-09-01

## Zmiany

- Naprawiono błąd `FloatingTextManager`, w którym `DrawString` było wykonywane bez poprawnie otwartego `SpriteBatch`.
- Dodano prawidłowy `SpriteBatch.Begin()` / `End()` w `FloatingTextManager.Draw()`.
- Usunięto zależność `InputManager` od legacy `PauseScreen`.
- `ESC` jest obsługiwane wyłącznie przez `GameplayScreen` jako wejście do pauzy/wznowienia.
- Przebudowano system pauzy: pauza jest stanem `GameplayScreen`, a `MyraPauseView` pozostaje wyłącznie warstwą UI.
- Usunięto runtime zależność od popupowego `PauseScreen` w `ScreenManager`.
- Resume, Save i Load są wykonywane przez logikę właściciela stanu gry, a nie przez render callback Myra.
- Zachowano wspólny `MyraUIManager`/`Desktop` dla Main Menu, Settings, About i Pause.
- Stan po dodatkowym drobnym bugfixie użytkownika został potwierdzony jako działający.

## Historia

`0.1.2pre` następuje po zamknięciu niezależnych etapów `0.1.2a`–`0.1.2k`. Etapy lettered są historyczne i nie powinny być przepisywane.

## Status

`0.1.2pre` jest aktualną wersją roboczą/stabilizacyjną. Nie jest jeszcze finalnym `0.1.2`.
