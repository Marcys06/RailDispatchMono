# Debug logging

## Problem fixed

The project already contained `DebugManager`, but its file logging was disabled by default and console output used only `Console.WriteLine`. In MonoGame hosts this is not a reliable way to see diagnostics in the IDE debugger. `ScreenManager` also had `TraceEnabled` defaulting to `false`.

## Current behavior

`DebugManager` now:

- has file logging enabled by default;
- writes to `Console.WriteLine` when console logging is enabled;
- writes to `System.Diagnostics.Debug.WriteLine`;
- writes to `System.Diagnostics.Trace.WriteLine`;
- stores the recent log history in memory;
- uses `%LOCALAPPDATA%/RailDispatchMono/Logs/debug_log.txt` when available;
- falls back to the application directory if the local application-data path cannot be resolved;
- never allows a logging failure to terminate the game.

`RailDispatchMonoGame` now emits lifecycle diagnostics during construction, initialization and content loading. `ScreenManager.TraceEnabled` is enabled during game initialization so the active screen list is also emitted.

## What to look at in Visual Studio

Run the game under the debugger and open:

`View -> Output`

Then select the debugger output stream. Messages generated by `DebugManager` should appear there.

The persistent file is useful when the process closes before the IDE output is inspected.

## Important warning

Do not log from `RailDispatchMonoGame.Update` or `Draw` on every frame unless the message is deliberately rate-limited. At 60 FPS this creates thousands of lines quickly and can itself affect performance.

For frame-level diagnostics use a counter, timer or conditional sampling.

## Categories

Available categories are:

- General
- Block
- Signal
- Train
- TrainMovement
- Camera
- Input
- Render
- Map
- TrackBuilder
- UI
- Performance
- Error
- All

`Performance`, `Camera`, `TrackBuilder` and `UI` remain disabled by default at the category level. Enable them explicitly when investigating those systems.

## Example

```csharp
DebugManager.Train("Train created: IC-123");
DebugManager.Signal("Signal changed to green");
DebugManager.LogError("Failed to load level");
```
